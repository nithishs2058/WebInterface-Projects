\# Web Interface Projects



A collection of 10 Web Interface projects developed as part of my CSE coursework. These projects demonstrate practical implementation of HTML, CSS, JavaScript, React.js, JSX, React Router, state management, props, Context API, form validation, and interactive user interfaces.



\## Technologies Used



\- HTML

\- CSS

\- JavaScript

\- React.js

\- JSX

\- React Router

\- Vite



\## Projects



\### 1. Counter App Using JavaScript Concepts



A simple interactive counter application developed using JavaScript concepts. The project demonstrates dynamic value updates and basic user interaction through JavaScript.



\### 2. Student Profile Card



A student profile application that accepts details such as name, roll number, and marks. It dynamically displays the student information and calculates the grade based on the entered marks using JavaScript conditional statements.



\### 3. Student Dashboard Using JSX Props



A React-based student dashboard developed to demonstrate JSX and props. Student information is passed between components using props and displayed through reusable React components.



\### 4. Hobbies List with Student Profile



A React-based student profile interface that displays student information along with a list of hobbies. The project demonstrates JSX concepts, component-based design, and dynamic rendering of student data.



\### 5. Calculator



A React-based calculator supporting addition, subtraction, multiplication, and division. It also includes decimal input, clear, backspace, expression display, keyboard-style number input, and error handling for invalid operations such as division by zero.



\### 6. Student Attendance Tracker



A React-based attendance management application for recording daily student attendance. Users can mark students as Present or Absent, while the application dynamically calculates the total number of marked, present, and absent students.



\### 7. Form Validation



A comprehensive web form validation project designed to validate different types of user input. The project includes PAN card validation, phone number validation with country code, username and Aadhaar name matching, email validation, password validation, permanent and current address handling, automatic address copying through a checkbox, photo size restrictions, required-field validation, and Submit and Clear buttons.



\### 8. Personal Portfolio Website



A multi-page personal portfolio website built using React and React Router. It includes Home, About, Skills, Projects, and Contact pages, along with responsive navigation, project information, skills, contact details, and an interactive contact form.



\### 9. To-Do List Application



A React-based task management application that allows users to add, complete, undo, and delete tasks. The project demonstrates React state management and the Context API for sharing task data and actions between components.



\### 10. Student Report Card



A React-based student report card application that uses the Context API to share student information between components. It calculates total marks, percentage, overall grade, and pass/fail status dynamically based on subject marks.
